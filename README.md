**Стажировки** — адаптивный сайт, созданный в рамках обучения. Проект представляет собой лендинг образовательного центра с адаптивной вёрсткой и минимальной интерактивностью.

## Технологии

- HTML5, BEM
- SCSS (Sass)
- JavaScript (табы, слайдеры, аккордионы)
- Vite (сборка проекта)
- SVG-спрайт
- Оптимизация изображений: использование <picture>, ретинизация
- Линтеры: ESLint, Stylelint, linthtml

## Возможности

- Фиксированная вёрстка для десктопа, планшета, мобильного.
- Минимальные анимации и интерактивные элементы
- Поддержка современных браузеров Chrome и Firefox
